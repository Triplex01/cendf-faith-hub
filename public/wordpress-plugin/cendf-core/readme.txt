Plugin principal pour la Sous-Commission Épiscopale pour la Doctrine de la Foi. Gère les types de contenu, API REST et fonctionnalités du site.

== Description ==

SCEDF Core est le plugin indispensable pour faire fonctionner le site de la Sous-Commission Épiscopale pour la Doctrine de la Foi (SCEDF) / Radio Espoir.

**Fonctionnalités incluses:**

* 10 types de contenu personnalisés (Événements, Podcasts, Enseignements, etc.)
* API REST complète pour le frontend React
* Champs ACF préconfigurés
* Bandeau défilant configurable
* Formulaire de contact sécurisé
* Newsletter intégrée
* Système de paiement mobile (Orange Money, Wave)
* Sécurité renforcée (CORS, rate limiting)

**Types de contenu:**

* Articles (natif WordPress)
* Événements
* Podcasts
* Programmes Radio
* Animateurs
* Enseignements
* Documents
* Archives
* Produits (Boutique)
* Activités

== Installation ==

1. Téléchargez le fichier ZIP du plugin
2. Allez dans Extensions > Ajouter > Téléverser une extension
3. Sélectionnez le fichier ZIP et cliquez sur "Installer maintenant"
4. Activez le plugin
5. Suivez l'assistant d'installation (menu "🔧 Installation")

== Frequently Asked Questions ==

= Ce plugin nécessite-t-il d'autres plugins ? =

Oui, le plugin installe automatiquement:
* Advanced Custom Fields (ACF) - pour les champs personnalisés
* ACF to REST API - pour exposer les champs via l'API

= Comment accéder à l'assistant d'installation ? =

Après activation, un menu "🔧 Installation" apparaît dans la barre latérale. Cliquez dessus pour lancer l'assistant.

= Le thème est-il obligatoire ? =

Le thème SCEDF Theme est recommandé pour le fonctionnement optimal du site React. Sans le thème, vous pouvez toujours utiliser l'API REST avec n'importe quel frontend.
